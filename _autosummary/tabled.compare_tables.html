tabled.compare_tables.columns_value_diff(df1, df2)[source]#

For each column present in both dataframes, compare the values row-wise. Returns a dict with column names as keys and DataFrames of differences as values. Only columns with differences are included.

tabled.compare_tables.dataframe_diffs(df1, df2, comparisons={'columns_diff': <function columns_diff>, 'columns_value_diff': <function columns_value_diff>, 'dtypes_diff': <function dtypes_diff>, 'index_diff': <function index_diff>, 'shape_diff': <function shape_diff>}, *, diff_condition=<class 'bool'>)[source]#

Compare the diff of dataframes using specified diff comparison functions.

Returns a dictionary with comparison names as keys and comparison results as values.

Parameters:

  • df1 (DataFrame) – The first dataframe to compare.

  • df2 (DataFrame) – The second dataframe to compare.

  • comparisons (Union[dict[str, Callable[[DataFrame, DataFrame], Any]], Sequence[Union[str, Callable[[DataFrame, DataFrame], Any]]], str, Callable[[DataFrame, DataFrame], Any]]) – A dictionary or list of comparison functions or names. Defaults to DFLT_COMPARISONS.

  • diff_condition (callable) – A function that determines whether to include a comparison result in the output dictionary based on the comparison result. Defaults to the built-in bool function.

Returns:

A dictionary with comparison names as keys and comparison results as values.

Return type:

dict

Example

>>> import pandas as pd
>>> df1 = pd.DataFrame({'A': [1, 2], 'B': [3, 4]}, index=[0, 1])
>>> df2 = pd.DataFrame({'A': [1, 2], 'C': [5, 6]}, index=[1, 2])
>>> diffs = dataframe_diffs(df1, df2)
>>> diffs
{'columns_diff': {'left_right': {'B'}, 'right_left': {'C'}},
 'index_diff': {'left_right': {0}, 'right_left': {2}},
 'columns_value_diff': {'A':    left  right
1     2      1}}
